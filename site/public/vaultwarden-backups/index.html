Vaultwarden Backups

This personal application backs up a private Vaultwarden instance to its operator's Google Drive. It is operated by Ny Hasinavalona Randriantsarafara.

The backup runs on the operator's server using restic and rclone. Restic encrypts the backup before it is uploaded. The Google connection is limited to files created or opened with this application; it does not grant access to the rest of the account's Drive files.

This is a private backup integration with no public signup. Family vault accounts do not connect their own Google accounts to the backup application.
